How it works

From idea to showcase in about a minute.

  1. 01

    Fill the form

    Open a submission issue. Add a title, links, a cover image and tags. No accounts or tools to set up.

  2. 02

    It publishes itself

    A GitHub Action reads the issue, adds your work to the directory and redeploys the site.

  3. 03

    Share the link

    Every project gets its own link. To update it, edit the issue and the site follows.
